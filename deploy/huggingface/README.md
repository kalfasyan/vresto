# vresto: public demo

Search the Copernicus catalogues, stream Sentinel-2 imagery onto the map, check coverage and
chart NDVI history, all without an account. To download bands, add your own free
[Copernicus account](https://dataspace.copernicus.eu/) in ☰ → Settings; it is kept only for
your browser tab.

This Space runs [vresto](https://github.com/kalfasyan/vresto) in public mode. To work with
local files or download without limits, install it yourself: `pip install vresto`.
